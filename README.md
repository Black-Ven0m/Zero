# ZEROHEX NETWORK

A static, responsive cyberpunk landing page inspired by the ZEROHEX NETWORK concept.

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the folder to GitHub Pages, Netlify, Vercel, or any static host.

## Customize
- Replace placeholder social/Telegram links in `index.html`.
- Update projects, bots, resources and status values.
- Edit `style.css` for colors and typography.
- Edit `script.js` for interactions.

This frontend is intentionally static; live service status should be connected to your own backend/API if needed.
